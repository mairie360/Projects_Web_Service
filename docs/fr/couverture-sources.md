# Mesure de couverture des sources

Exécuter `npm test` avec Node 24 et npm épinglés. La suite Node native tourne une fois avec un worker ; `c8@12.0.0` remappe ses vraies captures V8, puis Vitest mesure les composants et le composeur produit le rapport final. Les seuils natifs et Vitest restent bloquants. Le rapport final exige 60 % des lignes par module source et 60 % au total pour lignes, branches et fonctions ; l'exception existante du layout serveur reste déclarée explicitement là où elle s'applique.

`coverage/lcov.info` est le rapport primaire destiné à CI. L'autorité des mesures est déclarée avant exécution dans `scripts/coverage-scope.cjs` : les sources React gardent leurs enregistrements Vitest V8 ; les autres gardent leurs enregistrements Node/c8. Le composeur ne cumule pas les lignes incompatibles d'un simple import Node avec celles du composant et ne choisit pas le meilleur score. L'inventaire TS/TSX complet et les empreintes avant/après doivent correspondre.

Le LCOV natif, stdout, stderr, le statut et les captures brutes restent dans `coverage/native/`. Les rapports remappés et empreintes des sources/maps/entrées restent dans `coverage/source-mapped/`, les entrées et la provenance de composition dans `coverage/source-inputs/`. Les résultats précédents vont dans `coverage/history/`. L'archivage natif précède le retrait du chemin primaire. Map ou source embarquée absente, source modifiée et rapport invalide bloquent la publication primaire. Tout échec natif reste un échec du pipeline, même si le remappage réussit.

Les commandes individuelles `test:node` et `test:components` produisent des preuves intermédiaires ; utiliser `npm test` pour le rapport primaire complet. L'uploader CI partagé utilise ce rapport explicitement, sans recherche automatique. Les preuves brutes restent dans le workspace local/CI ; aucun archivage CI persistant ni envoi externe des captures brutes n'est ajouté. Les exigences d'audit et de publication restent séparées et inchangées.
